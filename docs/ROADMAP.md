# Roadmap

The detailed agreed order and exit criteria are in [EXECUTION_PLAN](EXECUTION_PLAN.md). Completed work and open verification are in [WORK_LOG](WORK_LOG.md); checks are in [VALIDATION](VALIDATION.md).

## Current implementation

ChatGPT-only official ZIP import; branch/snapshot archive; FTS5; separate-password SQLCipher vault; editable memory and briefs; source-aware sharing rules; selected Markdown preview/copy/file export; local authenticated MCP; encrypted backups; manual/idle/macOS lifecycle locking. Saves produce drafts and require a separate saved-version review before approval. The dark native interface and static landing assets exist.

This is a working private pre-release. Basic native review, sharing, recovery and fictional import workflows have evidence. Codex CLI and Grok Build have passed the fictional MCP client policy matrix. Native Finder drop/reimport, password change, Codex/Grok configuration screens and sharing-off after restart are now verified with fictional data. Representative real exports, full keyboard/lifecycle coverage and distribution gates remain open. Claude and Grok export imports are not yet supported; MCP-client compatibility is tracked separately in MCP_ACCEPTANCE.

## Agreed execution order

1. **M1, in progress:** dependable ChatGPT workflow; contextual sensitivity detection and safe reclassification; build/vault identity; native approval, isolated upgrade, real export and MCP checks.
2. **M2, implemented; basic native flow verified:** make exact sharing preview the centerpiece; selective copy and Markdown export with privacy/staleness enforcement.
3. **M3, implemented; validation in progress:** reviewed in-app restore/password change, preserved encrypted generations, client reset, conversation deletion and explicit raw-snapshot cleanup. Disposable recovery and lifecycle regression suites pass; native and durability limits remain documented.
4. **M4, planned:** Claude first, then Grok; synthetic fixtures by provider and observed format (ChatGPT contract fixtures now established); cross-provider provenance/privacy verification.
5. **M5, planned:** signed/notarized release, clean installation test, fictional-data demo, strong README and owner-approved public launch.

Apple enrollment is deferred to the end at the owner’s request. Enrollment is not confirmed. No account/legal/payment action is automatic.

## Retained backlog

Per-project/brief agent grants; direct brief retrieval; note/brief FTS and database pagination (bounded UI pages implemented); tagging/branch views; encrypted access metadata and revoke-all; signed-app Keychain client integration; broader backup-filesystem support; superseded decisions and suggested-memory inbox. These require explicit scheduling and must not silently expand a milestone.

No cloud sync, live capture, automatic extraction, paid model dependency, semantic embeddings, Gemini, mobile, teams, monetization or demand-testing work in this plan.

Keep the repository private and public download disabled until the owner explicitly chooses publication after the release gates pass.
