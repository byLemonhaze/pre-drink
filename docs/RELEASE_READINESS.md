### Limits to state before inviting anyone

- **Provider support:** one representative ChatGPT export has passed isolated backend and native post-import acceptance. Claude/Grok have versioned fictional contracts and isolation tests; present those adapters as experimental until representative official exports pass. Broader provider claims need those checks, not another ChatGPT test round.
- **Accessibility:** ordinary keyboard/focus/layout checks and spoken password/unlock labels have evidence. Automatic saving/completion speech remains unconfirmed. Do a human listening pass before claiming those announcements work; do not claim full accessibility conformance. If essential to a beta participant, verify it before inviting that participant.
- **Dependencies:** the SDK's unmaintained Chrono dependency remains active on macOS. Two other lockfile warnings are absent from both resolved Mac normal/build graphs. Keep DEPENDENCY_CHECKS and fresh audit results visible to the reviewer; an audit pass does not resolve these warnings.
- **Curation:** installed-client functional checks do not demonstrate broad model quality. Automatic publication stays an explicit narrow policy; do not promise accurate autonomous curation of an entire archive. Offline manual use does not require API credits.

### Public download comes afterward

Apple enrollment, Developer ID signing, notarization and a downloaded clean-install check remain last. Public source/download publication requires the owner's launch decision. No GitHub Actions runs or paid service are needed for the local acceptance above. OpenAI credit is available if a specific useful test needs it; none was used for this pass.

Physical power-loss testing, every old binary, all hardware and every future export format are continuing coverage goals, not an achievable universal certification or an endlessly moving beta checklist. Keep original exports and verified encrypted backups. A newly discovered blocking defect still requires a fix and focused revalidation.
