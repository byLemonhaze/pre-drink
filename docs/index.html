A FEW GOOD QUESTIONS

Before you
bring your history.

Is it actually free?

Yes. Pre-Drink is free and open source under the MIT license. Local features do not call a paid model. An assistant you connect may still use its own subscription allowance or API billing.

Does it work with every AI product?

Import currently supports official ChatGPT exports only. Approved context is exposed through standard local MCP for compatible assistants. Individual client setup and compatibility still need validation. Claude and Grok imports are planned later.

Does it decide what to remember?

You do. This version uses manual curation: select a message, edit the note, and explicitly approve it. There is no background AI extraction or automatic cloud upload.

What if I lose my password?

There is no reset or server-held recovery key. Keep encrypted backups and their passwords. Original exports can rebuild the archive, but not your manually edited notes and briefs.

Is the first release ready?

The native app and core flows are implemented. Public downloads are pending Apple signing/notarization and release validation. Representative real exports, larger libraries, and independent security review remain on the roadmap. No software can promise absolute security.
