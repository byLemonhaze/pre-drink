A FEW GOOD QUESTIONS

Before you
bring your history.

Is it actually free?

Yes. Pre-Drink is free and open source under the MIT license. Local features do not call a paid model. An assistant you connect may still use its own subscription allowance or API billing.

Does it work with every AI product?

Recognized ChatGPT, Claude and Grok exports feed the local vault. Local MCP supports compatible assistants; Codex and Grok Build have fictional retrieval evidence. New agent-writing quality checks remain open. This does not connect arbitrary web chats. Gemini and Copilot are future candidates.

Does it decide what to remember?

You control the policy. Curate manually offline, or optionally connect a same-provider agent to draft memory. Review complete batches; narrow automatic-sharing rules are separate and off by default. Automatic releases are labelled. No model runs in the app, and a local-model curator is not yet implemented.

What if I lose my password?

There is no reset or server-held recovery key. Keep encrypted backups and their passwords. Original exports can rebuild the archive, but not curated notes, session summaries, revision history or briefs.

Is the first release ready?

The native app and core flows are implemented. Public downloads are pending Apple signing/notarization and release validation. Representative real exports, model-led curation quality, broader scale coverage and independent security review remain open. No software can promise absolute security.
