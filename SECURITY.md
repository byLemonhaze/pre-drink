# Security reporting

Read docs/SECURITY.md for the security model and current limitations.

Report suspected vulnerabilities privately to the repository owner through an available private GitHub reporting channel. If none is configured, ask for a private channel without including exploit details or personal data in a public issue.

Use synthetic reproduction data. Never upload a real vault, chat export, password, MCP token, signing credential, or private screenshot. Do not post secrets even if a repository is private. No independent security audit or bug-bounty commitment is implied.
